# mcrvc
Собственный минималистичный аналог платформы Telegra.ph, работающий полностью на базе GitHub Pages и GitHub REST API без использования сторонних серверов и баз данных.

## 🚀 Особенности проекта

* **Чистый интерфейс:** Минималистичный дизайн в стиле Telegra.ph (удобная ширина для чтения, строгие шрифты).
* **Автономность:** Работает на бесплатном хостинге GitHub Pages.
* **Безопасность изображений:** Встроенная автоматическая очистка EXIF-метаданных (геолокация, данные камеры) прямо в браузере с помощью Canvas перед загрузкой фото в репозиторий.
* **Панель форматирования:** Быстрое добавление жирного текста, курсора, подзаголовков, цитат, ссылок и изображений.
* **Авторские права:** Поддержка имён авторов и ссылок на них под заголовками статей.
* **Безопасная авторизация:** Управление контентом защищено вашим личным токеном (`Personal Access Token`), который хранится локально в вашем браузере (`localStorage`).

## ⚙️ Установка и запуск
1. Создайте публичный репозиторий на GitHub.
2. Создайте в нём пустые папки `posts` и `images`.
3. Загрузите файл `index.html` (из этого репозитория) в корень.
4. В файле `index.html` замените строчку `YOUR_GITHUB_USERNAME/YOUR_REPO_NAME` на данные вашего репозитория.
5. Включите **GitHub Pages** в настройках репозитория (`Settings -> Pages -> Deploy from a branch -> main / root`).
6. Создайте в настройках GitHub классический токен с правом `repo` и используйте его для входа на вашем сайте.
